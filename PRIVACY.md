# Privacy

The SDK monitors only the page where it is installed and stops when consent is withdrawn. It does not collect passwords, OTPs, cookies, form contents, clipboard contents, page text, DOM snapshots, browser history, webcam, microphone, screen captures, or private-network data.

Collected diagnostics are limited to browser capability information, page route without query strings, visibility state, high-level connection status, performance metrics, and approved custom events.

Projects can configure explicit or implied consent, allowed origins, event allowlists, metadata policies, URL redaction, retention periods, IP anonymization, and visitor data deletion/export workflows.

Hashed IP addresses can help duplicate detection, but hashing alone does not necessarily make IP addresses anonymous.
